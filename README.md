# 智能日报生成器（sdr）

《软件工程职业技能实践》课程设计项目仓库。基于规范驱动开发（SDD）与 AI 编程工具，同一项目分两阶段实现：

| 阶段 | 周次 | 方法 | 产物 tag |
|---|---|---|---|
| 阶段一 | 第 1–2 周 | SDD 六阶段工作流 | `v1-sdd` |
| 阶段二 | 第 3–4 周 | Superpowers 六大工作流 | `v2-superpowers` |

## 目录结构

```
.
├── specs/                  # 三份核心规范（规格先行）
│   └── proposal.md         # 项目提案：目标 / 背景 / 范围（含"不做什么"）/ 技术约束 / 成功标准 / 术语
├── docs/                   # Word 交付物
│   ├── 业务调研报告-框架稿.docx
│   ├── 业务调研报告-第一章完成.docx
│   └── 业务调研纪要.docx      # 18 项访谈结论、需求基线、风险项
└── README.md
```

后续将补充 `design.md`、`tasks.md` 于 `specs/`，以及 `src/`、`tests/`（第 2 周起）。

## 提交规范

- 格式：`feat|fix|test|docs: [任务编号] 简述`
- 一次提交对应一个可验证的交付物（小步提交）
- 凭证（GitHub Token / 飞书凭证 / SMTP 授权码）一律通过环境变量注入，禁止入仓
