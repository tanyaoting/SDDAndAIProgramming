## 4. 性能实测（CS-11 / CS-12 / CS-10）

| 指标 | 实测 | 门槛 | 说明 |
|---|---|---|---|
| CS-11 单成员单日（三源采集 + 生成） | 25.5 ms | ≤ 30 000 ms | 三源均为进程内 Mock，100% 排除网络延迟；真实网络下主要成本为 GitHub/飞书 RTT |
| CS-12 团队汇总（10 人） | 2.0 ms | ≤ 60 000 ms | 10 人全部生成 + 汇总查询 + 渲染 |
| CS-10 历史查询（1000 条） | 约 19 ms | ≤ 2 000 ms | 本地索引 `UNIQUE(member_id, report_date)` 生效 |

结论：三项指标均大幅低于门槛，无需触发 ADR-001 的分页/并发改进。
CS-11 的数字不含真实网络，故仅作为本机处理开销的上界证据；真实环境需保留网络余量。
