命名：`YYYY-MM-DD-<被评对象>.md`，一次评审一份，评审人与被评人互不重叠（指导书要求互评）。

每份记录至少包含：

| 项 | 要求 |
|---|---|
| 评审对象 | 提交范围（commit 区间）或 PR 链接 |
| 检查项 | 是否测试先行、是否触碰红线条目（认证/隐私）、是否复制 v1 代码、SQL 是否越界查 `content`、时间是否只经 `dayKey` |
| 问题分级 | 阻塞 / 建议 / 提问（不要只写"看起来不错"） |
| 处置 | 每条问题的修复提交号或"接受风险"的理由 |
